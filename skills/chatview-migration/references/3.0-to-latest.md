# 3.0.x → latest

No API was removed after 3.0.0. These steps clear deprecation warnings and
review default changes that alter the UI.

## From < 3.1.0

### `Message.updateAt` deprecated in favor of `updatedAt`

Search: `updateAt` (constructor argument, field reads, `copyWith`).

Before: `message.copyWith(updateAt: DateTime.now())`

After: `message.copyWith(updatedAt: DateTime.now())`

`toJson()` writes both `updated_at` and the old `update_at` key, and
`fromJson()` reads either, so stored data keeps working.

### Dependencies are pinned to exact versions

chatview 3.1.0 depends on exact versions of `intl`, `image_picker`,
`url_launcher`, `emoji_picker_flutter`, `audio_waveforms`,
`cached_network_image`, `any_link_preview` and `chatview_utils`. If
`flutter pub upgrade --major-versions chatview` fails to resolve, widen the
app's own constraint on the package named in the error (often `intl`) rather
than adding a `dependency_overrides`.

### New defaults that change the UI

| Setting | Default | Effect | Keep the old look |
|---|---|---|---|
| `FeatureActiveConfig.enableMessageGrouping` | `true` | Consecutive messages from one sender within `messageGroupingThresholdMinutes` (1) are grouped; avatar and name appear once per group | `enableMessageGrouping: false` |
| `VoiceMessageConfiguration.showDuration` | `true` | Voice bubbles show the duration, read from the file when `voiceMessageDuration` is null | `showDuration: false` |

Opt-in features added in 3.1.0 (`enableMessageEditing` with
`ChatView.onEditTap`, `showTimeInChatBubble`, `playerMode`, …) are
documented in the `chatview-chat-screen` skill.

## From < next release (unreleased, after 3.1.0)

These changes are on `main` and not yet in a published version. Apply them
when the app uses a chatview newer than 3.1.0 (a git dependency or the next
release). No code change is required.

- Image messages now use `ImageMessageConfiguration.fit`, default
  `BoxFit.cover` (network images used `BoxFit.fitHeight`, others
  `BoxFit.fill`). Set `fit:` if image bubbles look cropped. A failed image
  shows a new placeholder; `errorBuilder: (context, imageUrl, error) => ...`
  replaces it.
- The sending indicator next to outgoing bubbles is now chosen by
  `ReceiptsWidgetConfig.sendingAnimationType` (default
  `SendingMessageAnimationType.slideOut`) and the "Seen" label animates in.
  A custom `receiptsBuilder` still replaces the indicator.
- `ChatViewLocale` gained `sending`, `sent`, `read` and `notDelivered`, with
  English defaults; add them to custom locales to translate them.
